# Only For You, Arpita ❤️

A romantic, heartfelt interactive slide website created with pure love and care.

## 🌸 Features
- **20 Complete Scripted Slides**: Crafted exactly according to the story with all custom messages and button prompts.
- **Romantic Velvet Twilight Aesthetic**: Frosted glassmorphism, animated glow orbs, and soft rose-gold gradients.
- **Slide 16 Laptop Mockup**: Displays Arpita's eyes picture as a laptop desktop wallpaper with a live clock and pinned sticky note.
- **Web Audio API Ambient Soundtrack**: Generates soothing, romantic Rhodes chords in real-time, plus chime sound effects with no external audio file dependencies.
- **Floating Rose Petals & Fireflies**: Dynamic interactive HTML5 Canvas background particle system.
- **Slide 20 Proposal & Three Meaningful Choices**:
  1. *Yes, I'd love to! 🥹❤️* — Celebratory fanfare, heart confetti explosion, sweet modal, and WhatsApp message button.
  2. *Need some time to think ⏳🌸* — Gentle, reassuring modal with no pressure and peaceful words.
  3. *Let's stay good friends 🤝🤍* — Warm, deeply respectful modal honoring her friendship and comfort.
- **Responsive & Mobile Ready**: Full touch swipe gesture support (swipe left/right), keyboard arrows (`←` and `→`), progress bar, and fullscreen toggle.

## 🚀 How to Run Locally
Simply double-click `index.html` to open it in any browser, or run a local static server:
```bash
# Using Node
npx serve .
# Or open directly in your favorite browser!
```

## 🌐 Deploy to GitHub Pages
1. Go to repository Settings on GitHub.
2. Under "Pages", select the `main` branch and `/ (root)` folder.
3. Save, and your live romantic surprise link will be ready to share with Arpita!
